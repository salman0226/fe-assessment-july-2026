## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/salman0226/fe-assessment-july-2026.git
```

Navigate to the project

```bash
cd fe-assessment-july-2026
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open your browser

```text
http://localhost:3000
```
